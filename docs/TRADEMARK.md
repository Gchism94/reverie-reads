# Trademark findings

Public-record search (USPTO via Justia/Trademarkia) of candidate names in the
software-relevant classes: **IC 9** (downloadable apps), **IC 42** (web/SaaS), **IC 41**
(online content/entertainment).

> **Not legal advice.** This reflects only US registered/pending records that are
> publicly indexed. It misses common-law (unregistered) names in use, foreign marks, and
> very recent filings. Before committing a name commercially, get a trademark attorney's
> clearance search and check app-store name availability.

| Name | Same-class finding | Read |
|---|---|---|
| **Reverie** (current) | Live **Class 9** word mark (Reg. 5433762, JTMD Ltd.) — apps for adjustable beds/mattresses/sound. Pending Class 35 (music PR). "Realms of Reverie" Class 9 abandoned. | Caution — same word & class, different field |
| **Nocturne** | Indexed Class 9 marks (game software; slippers) are **cancelled** | Clearer in software class, but very common word |
| **Vesper** | **Pending** app for audiobooks / downloadable novels (2025) | Caution — that's the books space, closest conflict |
| **Gloaming** | No same-class mark surfaced | **Cleanest** — rare word |
| **Lamplight** | "Lamplight Entertainment" registered in **Class 41**; lamp/candle goods elsewhere | Mixed — weigh the Class 41 mark |
| **Belladonna** | "Belladonna Entertainment" registered in **Class 9** | Higher concern — same class + adult-industry name baggage |
| **Lagniappe** | Prior Class 9 filing **abandoned** | Clearer in software; widely used by businesses generally |
| **Wisteria** | No software-class mark; known as a home-décor brand (other classes) | Probably OK in software; verify vs. home-goods marks |
| **Vieux Carré · Velvet Hour · Magnolia Dawn** | Not yet searched | Multi-word & uncommon → lower collision odds; still verify |

## Recommendation
- **Gloaming** is the cleanest in-class option and fits the dusk aesthetic.
- **Nocturne** and **Lagniappe** are workable in the software class but are common words
  worth a deeper sweep.
- **Vesper** and **Belladonna** are the most cautionary.
- Keeping **Reverie** means coexisting with an existing same-class (different-field) mark.

Note: "Nocturne" and "Magnolia Dawn" currently serve as the two **theme** names, which is
a low-risk use regardless of the app name decision.
