# Drop design tool exports here

Put the finished design output from design tool in this folder so coding agent can
reference it directly — exported screens, component code/snippets, an SVG/PNG of the
mockups, or a tokens file.

The canonical, text-form design spec (the two themes Nocturne + Magnolia Dawn, type,
motion, components) already lives in `../DESIGN_SYSTEM.md`. If anything here disagrees
with that file, update `DESIGN_SYSTEM.md` so there's a single source of truth.
